# Boss Loadouts

Dycel's Boss Loadouts is a mod which adds a menu (Toggleable with a keybind) to save and equip loadouts, grouped by folders, as well as keybinds to switch between loadouts or reload them.
Of course, to allow permanent buffs and defeated bosses to be easier to manage, the mod also adds a menu for managing them.
Each loadout is a copy of your inventory, armor, accessories, mount, hook, ammo, permanent buffs and defeated bosses.
All loadouts are stored on your PC, to access them click "Explorer" on any folder which will open up that folder in your file explorer, allowing you to share your loadouts, or take loadouts from other players.

The mod is primarily for nohitting without having to manually take the gear for each boss, but can be used by anyone wanting to fight bosses without the boring part of loadouts.
